# Chat is the only intake

The dashboard shows what the household already has. A person sends an event, an inventory correction, a recipe, a screenshot, or a receipt in Chat, as one message with or without a photo. There is no login. Settings holds the theme and the connection switches.

**Status:** accepted (2026-10-25).

Home, Calendar, Meals, and Inventory each had a form. That split intake across screens that should stay readable from across the room. Chat keeps the message as a proposal. With the reader off, the message stays visible and is not sent to a model. Calendar and the API connection stay "not connected" until a later connector, and those switches do not take a token. The theme is still remembered in the app. The control lives on Settings.
